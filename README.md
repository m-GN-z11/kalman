# 卡尔曼滤波器

## 概述
实现了一个8维状态、4维观测的卡尔曼滤波器，用于融合位置、面积、能量等多源传感器数据，并进行状态估计与预测。

## 状态向量与观测向量
- **状态向量** `x` (8维)：  
  `[cx, cy, vx, vy, area, darea, energy, denergy]`
  - `cx, cy`：目标中心坐标  
  - `vx, vy`：对应速度  
  - `area`：目标面积  
  - `darea`：面积变化率  
  - `energy`：目标能量  
  - `denergy`：能量变化率  

- **观测向量** `z` (4维)：  
  `[meas_cx, meas_cy, meas_area, meas_energy]`  
  直接测量位置、面积和能量。

## 系统模型

### 状态转移矩阵 F
采用匀速/恒变化率模型，在预测步骤中根据时间步长 `dt` 动态构建：
```
F = I (8x8)
F[0][2] = dt   (cx 受 vx 影响)
F[1][3] = dt   (cy 受 vy 影响)
F[4][5] = dt   (area 受 darea 影响)
F[6][7] = dt   (energy 受 denergy 影响)
```
其他对角元素为1，即其余状态量保持不变。

### 观测矩阵 H (4×8)
直接从状态中提取对应测量分量：
```
H[0][0] = 1.0   (测量cx)
H[1][1] = 1.0   (测量cy)
H[2][4] = 1.0   (测量area)
H[3][6] = 1.0   (测量energy)
```
其余元素均为0。

### 噪声协方差
- **过程噪声协方差 Q** (8×8，对角阵)：  
  根据经验设定，位置/面积/能量的不确定性大于速度/导数项。
- **测量噪声协方差 R** (4×4，对角阵)：  
  对应各传感器的测量方差，使用前可根据传感器特性调整。

## 算法流程

### 初始化 `kf_init`
- 输入初始状态 `x0`、初始协方差 `P0`，以及固定的 `Q`、`R`。
- 构建 `H` 矩阵和初始 `F`（单位阵）。
- 返回 `KalmanFilter` 结构体。

### 预测 `kf_predict(kf, dt)`
1. 根据 `dt` 重新生成状态转移矩阵 `F`。
2. 状态预测：  
   `x ← F * x`
3. 协方差预测：  
   `P ← F * P * Fᵀ + Q`

### 更新 `kf_update(kf, z)`
1. 计算新息（残差）：  
   `y = z - H * x`
2. 计算新息协方差：  
   `S = H * P * Hᵀ + R`
3. 计算卡尔曼增益：  
   `K = P * Hᵀ * S⁻¹`
4. 状态更新：  
   `x ← x + K * y`
5. 协方差更新：  
   `P ← (I - K * H) * P`
6. 对称化处理（避免数值不对称）：  
   `P[i][j] = P[j][i] = 0.5 * (P[i][j] + P[j][i])`

## 依赖的基础运算
- 矩阵/向量乘法、加法、减法、转置
- 方阵求逆（Gauss‑Jordan消元，含选主元）
- 所有运算均采用 `std::vector<std::vector<double>>` 实现。

# 测试与仿真

## 真实轨迹生成
使用预设的多项式函数生成8个真实状态（随时间连续变化）：
- `cx(t)`, `cy(t)`, `vx(t)`, `vy(t)`, `area(t)`, `darea(t)`, `energy(t)`, `denergy(t)`
- 均为4次多项式，模拟目标的非线性运动与特性变化。

## 传感器噪声仿真 `SensorNoise`
使用FastNoiseLite库，设计了多层噪声模型。
每个通道（cx, cy, area, energy）使用独立的随机种子和略微不同的参数，以获得独立的噪声形态。

## 主仿真流程

### 参数设置
- 时间步长 `dt = 0.1`
- 滤波阶段步数 `steps = 50`，覆盖 t = 0 ~ 5.0
- 预测阶段步数 `forecast_steps = 1`，纯预测至 t = 5.1

### 初始状态
- 真值初始值由轨迹函数在 t=0 给出。
- 滤波器初始估计在真值基础上加入少许偏差（`vx +0.5`, `vy -0.3`）。
- 初始协方差矩阵设为 `100 * I`，表示高度不确定。

### 实验步骤
**阶段1：滤波（t = 0 ~ 5.0，51个点）**
1. 计算当前时刻真实状态。
2. 调用各通道 `SensorNoise` 生成噪声，叠加到真实值得到含噪测量。
3. 若为第一步（t=0），直接进行更新；否则先预测再更新。
4. 输出时间、真值、测量值、滤波状态、预报标志(0)。

**阶段2：纯预测（t = 5.1，1个点）**
1. 仅执行预测（`kf_predict`），**不使用任何测量更新**。
2. 输出真值，测量值列输出 `NaN`，预报标志记为 `1`。
3. 此阶段用于评估滤波器的外推精度。

### 输出文件
- 所有结果写入 `kalman_output.txt`。
- 格式：空格分隔，每列依次为：  
  `t, true_cx, true_cy, meas_cx, meas_cy, filt_cx, filt_cy, true_vx, true_vy, filt_vx, filt_vy, true_area, meas_area, filt_area, true_energy, meas_energy, filt_energy, is_forecast`
- 数值保持6位小数，方便直接绘图或数据分析。
### 画图
- 把`kalman_output.txt`放到python画图代码的目录下，进行画图。
